| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

Security and cryptographic integrity are paramount to `open-evidence`. If you discover a vulnerability, potential hash collision edge case, or parser bypass:

1. **Do not create a public GitHub Issue.**
2. Please privately email the maintainer at `huangbuqubunao@gmail.com` with:
   - A detailed description of the vulnerability.
   - Minimal reproduction code or test vector.
   - Any proposed remediation.
3. We will acknowledge receipt within 48 hours and coordinate a coordinated disclosure timeline.
