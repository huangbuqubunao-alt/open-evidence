## Reporting a Vulnerability

Security and cryptographic integrity are paramount to `open-evidence`. If you discover a vulnerability, potential hash collision edge case, or parser bypass:

1. **Do not create a public GitHub Issue.**
2. Please report the vulnerability privately via **GitHub Security Advisories** on the repository page:
   - Go to the **Security** tab of the repository on GitHub.
   - Click **Report a vulnerability** to submit a private disclosure.
3. We will acknowledge receipt within 48 hours and coordinate a disclosure timeline.
